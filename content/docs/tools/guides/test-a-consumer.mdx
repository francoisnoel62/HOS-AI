This guide will show how to test a system that receives HOS facts, whatever its language, with `hos conformance run`:

- how it works: hos starts your program, sends it the whole scenario on its standard input, then reads one answer per delivery on its standard output;
- the input and output formats;
- a suggested path: pass `--level normative` first with the Python example, then the reference level;
- `--all`, scenario names, `--timeout`, `--scenario-dir` for your own scenarios, and `--junit`;
- an exercise: remove deduplication from the Python example, and read the report.

Meanwhile, the [conformance protocol](/spec/0.1/conformance/PROTOCOL.md) describes the exchange, and the [Python example](https://github.com/francoisnoel62/HOS-AI/tree/master/examples/python-dispositions) implements the normative level.
