This reference will describe the SDK's three entry points and every function, with its signature, its purpose, an example and the errors it throws:

- `@hos-ai/sdk`, for Node and the browser, with the schemas built in: validation, the processing rules, writing facts, time helpers, the producer check, signing and the conformance helpers;
- `@hos-ai/sdk/node`, which loads scenarios from files;
- `@hos-ai/sdk/reference`, the arrival-readiness reference projection, which is not normative;
- the generated types, one per event.

Meanwhile, the [npm page of the SDK](https://www.npmjs.com/package/@hos-ai/sdk) documents each entry point.
