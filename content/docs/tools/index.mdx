This overview will explain what each tool is for, help you choose between them, and say plainly what they do not do.

- **The hos command** (`@hos-ai/cli`) checks HOS files, replays event streams, tests a system in any language against the conformance scenarios, checks what a producer publishes, and signs producer manifests. It needs no code.
- **The SDK** (`@hos-ai/sdk`) does the same checks from TypeScript or JavaScript, in Node or in a browser, and helps build an adapter that publishes HOS facts.
- Neither certifies anything: passing the scenarios is a self-check, and no HOS certification exists yet. They are not a production processor or a live connector either.

Meanwhile, the [npm page of the hos command](https://www.npmjs.com/package/@hos-ai/cli) has a five-minute start.
