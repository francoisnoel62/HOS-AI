## Ask on GitHub

Questions and problems with the tools go to the project's GitHub issues, with the [template for the CLI and the SDK](https://github.com/francoisnoel62/HOS-AI/issues/new?template=cli-sdk-problem.yml). It asks for:

- the output of `hos --version` and `node --version`;
- your system, for example Windows 11 with PowerShell;
- the exact command, and everything it printed, with `--json` when the command has it;
- a file that shows the problem, if there is one.

The repository is public. Use synthetic data only: never real guest data, credentials, API keys or private keys.

## Report a vulnerability

A security problem does not go in a public issue: follow the [security policy](https://github.com/francoisnoel62/HOS-AI/blob/master/SECURITY.md).
